# Atividades (2.0pts)

### 1. Saudação Personalizada  
Desenvolva um aplicativo que contenha um campo de texto (`TextInput`) para que o usuário digite seu nome. Ao pressionar um botão, o sistema deve exibir uma mensagem de saudação no formato: “Olá, {nome}”.

---

### 2. Validação de Entrada  
Crie um aplicativo semelhante ao anterior, porém com a seguinte condição:  
Caso o usuário pressione o botão sem digitar nenhuma informação, o sistema deve exibir a mensagem: “Digite algo antes de continuar”. Caso contrário, deve exibir o texto normalmente.

---

### 3. Contador de Caracteres  
Implemente um aplicativo em que o usuário digite um texto e, ao pressionar um botão, seja exibida a quantidade de caracteres digitados.

---

### 4. Transformação de Texto  
Desenvolva um aplicativo que permita ao usuário digitar um texto e utilizar dois botões:  
- Um botão deve converter o texto para letras maiúsculas  
- Outro botão deve converter o texto para letras minúsculas  

O resultado deve ser exibido na tela.

---

### 5. Simulador de Acesso  
Implemente um aplicativo com dois campos de entrada: “usuário” e “senha”.  
Ao pressionar um botão, o sistema deve verificar se os dados correspondem aos seguintes valores:

- Usuário: @admin#  
- Senha: @!010203

Regras:
- Se os dados estiverem corretos, exibir: “Acesso permitido”  
- Caso contrário, exibir: “Acesso negado”  
- Se algum campo estiver vazio, exibir: “Preencha todos os campos”
